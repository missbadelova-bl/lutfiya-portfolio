# Lutfiya Badelova — shaxsiy portfolio

Google Stitch'da chizilgan "Editorial Serenity" dizayni asosida React (Vite + Tailwind CSS) da qurilgan shaxsiy landing page.
AI kursi, 13-dars uyga vazifasi: Stitch dizayni → React → GitHub → Vercel.

## Matnni o'zgartirish
Barcha matnlar va kontaktlar `src/data.js` faylida. Telegram va Uzum havolasini shu yerda yozing.

## Kompyuterda ishga tushirish
```
npm install
npm run dev
```

## Vercel
vercel.com → Add New → Project → shu repo'ni Import → Deploy. Framework: Vite (avtomatik aniqlanadi).
